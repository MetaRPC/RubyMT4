    MT4Service — Symbols & Quotes (Mid-Level API)¶

    12 methods for market data: typed quotes, the symbol list, Market Watch, snake_case symbol specs, tick value, and OHLC bars.

    🧩 API Layer: MID-LEVEL — a friendly facade over MT4Account. Returns typed Quote and SymbolSpec Structs instead of protobuf.

    Implementation: lib/metarpc_mt4/mt4_service.rb, wrapping quote / quote_many / symbols / symbol_select / symbol_params_many / tick_value_with_size / bars / quote_history on MT4Account.

    Demos: examples/demos/service/04_service_demo.rb.

    📋 All 12 methods¶

    Method Returns Low-level equivalent
    quote(symbol) Quote (Struct) quote, composed with spread
    quote_many(symbols) [Quote] quote_many, composed
    tick(symbol) QuoteData quote (raw passthrough)
    symbols [String] symbol_list
    symbol_exist?(symbol) Boolean symbol_list.include?
    select_symbol(symbol, select = true) Boolean symbol_select
    symbol_params(symbol) SymbolSpec (Struct) / nil symbol_params_many(symbol) → spec

    tick_value_with_size(symbols) [SymbolTickValueWithSizeInfo] tick_value_with_size
    bars(symbol, timeframe:, from_utc:, to_utc:, page_size:) [QuoteHistoryBar] bars
    last_bars(symbol, timeframe:, count:) [QuoteHistoryBar] bars, widening the window
    quote_history(symbol, timeframe:, from_utc:, to_utc:) [HistoryQuote] quote_history (legacy)

    📦 Quote (Struct)¶

    Returned by quote / quote_many:

    Field Type Description
    symbol String The symbol.
    bid Float Best bid.
    ask Float Best ask.
    high Float Session high.
    low Float Session low.
    spread Float ask - bid, computed for you.
    time_utc Timestamp Tick time in UTC.

    📦 SymbolSpec (Struct)¶

    Returned by symbol_params / symbol_params_all — the PascalCase SymbolParamsManyInfo normalized to snake_case:

    Field Type Description
    name String Symbol name.
    digits Integer Price decimals.
    point Float Point size.
    contract_size Float Units per lot.
    volume_min / volume_max / volume_step Float Lot sizing bounds.
    stops_level / freeze_level Integer Min SL/TP & freeze distance (points).
    tick_size / tick_value Float Price / money per tick.
    trade_mode / exe_mode / calc_mode Symbol Trade / execution / margin-calc mode.
    currency_base / currency_profit / currency_margin String Currencies.
    swap_long / swap_short Float Swaps.
    description / path String Human description / Market Watch path.
    selected Boolean In Market Watch?
    bid Float Last bid.
    time_utc Integer Spec time (UTC).
    raw SymbolParamsManyInfo The original protobuf, for any field not surfaced.

    📖 Method details¶

    quote(symbol) -> Quote¶

    Usage examples:

    1. Bid / ask / spread: 
      q = service.quote("EURUSD")
puts "bid #{q.bid}  ask #{q.ask}  spread #{q.spread.round(5)}"
    2. Session high/low: 
      q = service.quote("EURUSD")
puts "H #{q.high}  L #{q.low}"
    3. Tick time in UTC: 
      puts Time.at(service.quote("EURUSD").time_utc.seconds).utc.iso8601

    quote_many(symbols) -> [Quote]¶

    Usage examples:

    1. Watchlist: 
      service.quote_many(%w[EURUSD GBPUSD]).each { |q| puts "#{q.symbol} #{q.bid}/#{q.ask}" }
    2. Index by symbol: 
      by = service.quote_many(%w[EURUSD GBPUSD]).to_h { |q| [q.symbol, q] }
puts by["EURUSD"]&.ask
    3. Spread scan: 
      service.quote_many(service.symbols.first(10)).each { |q| puts "#{q.symbol} #{q.spread.round(5)}" }

    tick(symbol) -> QuoteData¶

    The raw protobuf quote when you want the untouched message.

    Usage examples:

    1. Raw bid/ask: 
      t = service.tick("EURUSD")
puts "#{t.bid}/#{t.ask}"
    2. Tick timestamp: 
      puts service.tick("EURUSD").date_time_utc.seconds
    3. Compare raw vs typed: 
      puts service.tick("EURUSD").ask == service.quote("EURUSD").ask

    symbols -> [String] · symbol_exist?(symbol) -> Boolean¶

    Usage examples:

    1. Count & membership: 
      puts "total #{service.symbols.size}, has EURUSD? #{service.symbol_exist?('EURUSD')}"
    2. Filter a family: 
      puts service.symbols.select { |s| s.include?("USD") }.size
    3. Guard an unknown symbol: 
      abort "no such symbol" unless service.symbol_exist?("EURUSD")

    select_symbol(symbol, select = true) -> Boolean¶

    Usage examples:

    1. Add to Market Watch: 
      service.select_symbol("XAUUSD")
    2. Ensure a set is watched: 
      %w[EURUSD GBPUSD USDJPY].each { |s| service.select_symbol(s) }
    3. Remove when done: 
      puts service.select_symbol("XAUUSD", false) ? "removed" : "in use"

    symbol_params(symbol) -> SymbolSpec · symbol_params_all -> [SymbolSpec]¶

    1. One spec: 
      s = service.symbol_params("EURUSD")
puts "digits #{s.digits}  vol #{s.volume_min}–#{s.volume_max} step #{s.volume_step}  contract #{s.contract_size}"
    2. Round a volume: 
      s = service.symbol_params("EURUSD")
vol = ((0.037 / s.volume_step).floor * s.volume_step).clamp(s.volume_min, s.volume_max)
    3. All specs as a lookup: 
      by = service.symbol_params_all.to_h { |s| [s.name, s] }
puts by["XAUUSD"]&.contract_size

    tick_value_with_size(symbols) -> [SymbolTickValueWithSizeInfo]¶

    Usage examples:

    1. Read tick value: 
      info = service.tick_value_with_size("EURUSD").first
puts "tick value #{info.TradeTickValue}  contract #{info.TradeContractSize}"
    2. Batch: 
      service.tick_value_with_size(%w[EURUSD XAUUSD]).each { |i| puts "#{i.symbolName} #{i.TradeTickValue}" }
    3. Money per tick for sizing: 
      tv = service.tick_value_with_size("EURUSD").first.TradeTickValue
puts "risk per 200 ticks at 0.1 lot: #{(tv * 200 * 0.1).round(2)}"

    bars(symbol, timeframe: :M1, from_utc:, to_utc: nil, page_size: 1000) -> [QuoteHistoryBar]¶

    Usage examples:

    1. Last day of M5: 
      bars = service.bars("EURUSD", timeframe: :M5, from_utc: Time.now.to_i - 86_400)
puts "#{bars.size} bars, last close #{bars.last&.close}"
    2. A fixed window: 
      service.bars("EURUSD", timeframe: :H1, from_utc: Time.utc(2026,1,1).to_i, to_utc: Time.utc(2026,1,8).to_i).size
    3. Average H1 range: 
      b = service.bars("EURUSD", timeframe: :H1, from_utc: Time.now.to_i - 86_400)
puts (b.sum { |x| x.high - x.low } / [b.size, 1].max).round(5)

    last_bars(symbol, timeframe: :M1, count: 50) -> [QuoteHistoryBar]¶

    The newest N bars — widens the lookback until enough exist (weekends / holidays).

    Usage examples:

    1. Newest 24 H1 closes: 
      service.last_bars("EURUSD", timeframe: :H1, count: 24).each { |b| puts b.close }
    2. Latest close: 
      puts service.last_bars("EURUSD", timeframe: :M5, count: 1).last&.close
    3. Simple SMA(20): 
      c = service.last_bars("EURUSD", timeframe: :M15, count: 20).map(&:close)
puts (c.sum / c.size).round(5)

    quote_history(symbol, timeframe: :M1, from_utc:, to_utc: Time.now.utc) -> [HistoryQuote]¶

    The legacy bar endpoint (deprecated — prefer bars).

    Usage examples:

    1. Last day of H1 (legacy): 
      puts service.quote_history("EURUSD", timeframe: :H1, from_utc: Time.now.utc - 86_400).size
    2. Read bar times: 
      service.quote_history("EURUSD", timeframe: :M15, from_utc: Time.now.utc - 3600)
       .each { |b| puts "#{Time.at(b.time_utc.seconds).utc.strftime('%H:%M')} C#{b.close}" }
    3. Last close: 
      puts service.quote_history("EURUSD", timeframe: :H1, from_utc: Time.now.utc - 86_400).last&.close
