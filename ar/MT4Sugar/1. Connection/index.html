    MT4Sugar — Connection (High-Level API)¶

    One-liners to connect, check health, and disconnect — plus the quick_connect positional shorthand.

    🧩 API Layer: HIGH-LEVEL — delegates to MT4Service / MT4Account.

    Implementation: lib/metarpc_mt4/mt4_sugar.rb. Demos: examples/demos/main.rb (connects once for every demo).

    ← MT4Sugar Overview

    📋 All 11 methods¶

    Method Returns Notes
    connect(login, password, server:, **opts) ConnectData ConnectEx by broker server name
    connect_by_host(login, password, host:, port:, **opts) ConnectData by raw host:port
    connect_proxy(login, password, **opts) ConnectProxyData through a proxy
    quick_connect(login, password, server) ConnectData positional-server shorthand
    get_id(login = nil, password = nil) String resolve the session id (GetId)
    connected? Boolean local connected flag
    reconnect(force: false) ReconnectData re-establish the broker link
    disconnect(delete: false, reason: nil) DisconnectData stop the terminal
    check_connect CheckConnectData health check
    connect_state ConnectStateData current state
    connection_status ConnectionStatusData current status

    🏗️ How these are built¶

    These are thin passthroughs to the connection helpers on MT4Account (via MT4Service) — the sugar layer adds friendly names, not new logic:

    sugar.connect → service.connect → account.connect → Connection.ConnectEx RPC
    • connect / connect_by_host / connect_proxy → ConnectEx / Connect / ConnectProxy. quick_connect is connect with a positional server.
    • get_id → GetId; reconnect → Reconnect; disconnect → Disconnect.
    • connected? reads a LOCAL flag (no round-trip). check_connect / connect_state / connection_status are the live health-check RPCs.

    📖 Method details¶

    connect(login, password, server:, **opts) -> ConnectData¶

    Connect by broker server name (ConnectEx). Raises InvalidLoginError on bad credentials.

    Usage examples:

    1. Basic connect: 
      mt4.connect(1235959737, "password", server: "EGlobal-Demo")
    2. With a stable terminal id (set on create): 
      mt4 = MetaRPC::MT4::MT4Sugar.create(api_key: ENV["MRPC_API_KEY"], id: stable_uuid)
mt4.connect(1235959737, "password", server: "EGlobal-Demo", name: "bot")
    3. Guard bad credentials: 
      begin
  mt4.connect(1235959737, "wrong", server: "EGlobal-Demo")
rescue MetaRPC::MT4::InvalidLoginError => e
  warn "bad login: #{e.message}"
end

    connect_by_host(login, password, host:, port:, **opts) -> ConnectData¶

    Connect by the broker trade server's raw host:port (Connect).

    Usage examples:

    1. Connect by host:port: 
      mt4.connect_by_host(1235959737, "password", host: "1.2.3.4", port: 443)
    2. With a label: 
      mt4.connect_by_host(1235959737, "password", host: "1.2.3.4", port: 443, name: "bot")

    connect_proxy(login, password, **opts) -> ConnectProxyData¶

    Connect through a SOCKS/HTTP proxy (ConnectProxy).

    Usage examples:

    1. Through a SOCKS/HTTP proxy: 
      mt4.connect_proxy(1235959737, "password", host: "1.2.3.4", port: 443,
                  proxy_host: "10.0.0.1", proxy_port: 1080, proxy_type: :PROXY_TYPE_SOCKS5)
    2. With proxy auth: 
      mt4.connect_proxy(1235959737, "password", host: "1.2.3.4", port: 443,
                  proxy_host: "10.0.0.1", proxy_port: 1080, proxy_type: :PROXY_TYPE_HTTP,
                  proxy_user: "u", proxy_password: "p")

    quick_connect(login, password, server) -> ConnectData¶

    Positional-server shorthand (no server: keyword).

    Usage examples:

    1. One line: 
      mt4.quick_connect(1235959737, "password", "EGlobal-Demo")
    2. From env: 
      mt4.quick_connect(ENV["MT4_LOGIN"].to_i, ENV["MT4_PASSWORD"], ENV["MT4_SERVER"])

    get_id(login = nil, password = nil) -> String¶

    Resolve the terminal session id without connecting.

    Usage examples:

    1. Resolve by credentials: 
      puts mt4.get_id(1235959737, "password")
    2. Reuse the cached id after connect: 
      mt4.connect(1235959737, "password", server: "EGlobal-Demo")
puts mt4.account.id

    connected? -> Boolean¶

    A LOCAL flag set on connect — it does NOT ping the server; use the health checks for a live round-trip.

    Usage examples:

    1. Check: 
      puts mt4.connected?
    2. Guard before trading: 
      abort "not connected" unless mt4.connected?

    reconnect(force: false) -> ReconnectData¶

    Re-establish the broker link with the stored parameters (Reconnect).

    Usage examples:

    1. Re-establish: 
      mt4.reconnect
    2. Force it: 
      mt4.reconnect(force: true)

    disconnect(delete: false, reason: nil) -> DisconnectData¶

    Stop the terminal (Disconnect); delete: true also removes it from the account list.

    Usage examples:

    1. Stop (keep the terminal warm): 
      mt4.disconnect
    2. Stop and remove the terminal: 
      mt4.disconnect(delete: true)

    check_connect · connect_state · connection_status¶

    Health checks (return the raw *Data).

    Usage examples:

    1. Is the terminal attached? 
      puts mt4.check_connect
    2. Current state / status: 
      puts mt4.connect_state
puts mt4.connection_status
