# RubyMT4 SDK

> Idiomatic Ruby gem SDK for MetaTrader 4 algorithmic trading automation.

[![Docs](https://img.shields.io/badge/docs-metarpc.github.io%2FRubyMT4-blue.svg)](https://metarpc.github.io/RubyMT4/)
[![License: MIT](https://img.shields.io/badge/License-MIT-yellow.svg)](https://opensource.org/licenses/MIT)

## Features

- **Pure Ruby**: Zero external C-extension or desktop terminal dependencies.
- **Idiomatic Ruby API**: Clean keyword arguments, block-based streaming, and hash summaries.
- **Full Order Lifecycle**: Open, modify (SL/TP), and close market and pending orders.
- **Real-Time Data**: Live tick streams and historical candle bars.

Full documentation is available at [https://metarpc.github.io/RubyMT4/](https://metarpc.github.io/RubyMT4/).
