# MT4Sugar — History & Statistics (High-Level API)

> Closed-order history and the four trade-statistics reads, as one-liners.

**🧩 API Layer:** **HIGH-LEVEL** — passthroughs to [`MT4Service`](../MT4Service/1.%20Account_Information.md) history/stats methods.

**Implementation:** `lib/metarpc_mt4/mt4_sugar.rb`. **Demos:** `examples/demos/sugar/09_sugar_history.rb`.

[← MT4Sugar Overview](./MT4Sugar.API_Overview.md)

---

## 📋 All 5 methods

| Method | Returns | Description |
|--------|---------|-------------|
| **`order_history(from_utc:, **opts)`** | `[HistoryOrderInfo]` | closed / deleted orders (auto-paged) |
| **`trade_stats(from_utc:, from:)`** | `StatsData` | aggregate statistics |
| **`trade_stats_equity_history(from_utc:, from:, exclude_same_bars:)`** | `StatsWithChartsData` | stats + equity chart |
| **`equity_history(from_utc:, from:, exclude_same_bars:)`** | `[EquityPointData]` | equity-curve points |
| **`trade_unrealized_pl(from_utc:, from:)`** | `[TradeUnrealizedExtremaData]` | per-order MFE/MAE |

> Stats take a start time as `from_utc` (UTC) **or** `from` (broker time), sent as ISO-8601 strings; omit for full history.

---

## 🏗️ How these are built

Two different services: `order_history` comes from `AccountHelper.OrdersHistory` (auto-paged), the stats from the separate `TradeStats` service (the server aggregates):

```
sugar.order_history → account.orders_history → AccountHelper.OrdersHistory (paged → one array)
sugar.trade_stats   → account.trade_stats   → TradeStats.TradeStats
```

* **History** window bounds are `Timestamp`s; **stats** window bounds are **ISO-8601 strings** (the SDK converts a Ruby `Time` for you) — an MT4-specific split.
* `trade_stats` / `trade_stats_equity_history` / `equity_history` / `trade_unrealized_pl` all live on the `TradeStats` service.

## 📖 Method details

### `order_history(from_utc:, **opts) -> [HistoryOrderInfo]`

*Closed / deleted orders in a window — auto-paged into one array (`OrdersHistory`).*

**Usage examples:**

1. Last 7 days, net P/L:
   ```ruby
   h = mt4.order_history(from_utc: Time.now.utc - 7 * 24 * 3600)
   puts "closed #{h.size}, net #{h.sum(&:profit).round(2)}"
   ```
2. Newest first:
   ```ruby
   mt4.order_history(from_utc: Time.now.utc - 86_400, sort: :HISTORY_SORT_BY_CLOSE_TIME_DESC)
      .first(5).each { |o| puts o.ticket }
   ```
3. Per-symbol:
   ```ruby
   mt4.order_history(from_utc: Time.now.utc - 30 * 24 * 3600)
      .group_by(&:symbol).each { |s, r| puts "#{s}: #{r.sum(&:profit).round(2)}" }
   ```

### `trade_stats(from_utc: nil, from: nil) -> StatsData`

*Server-aggregated stats (`TradeStats.TradeStats`); `from_utc` is sent as an ISO-8601 string.*

**Usage examples:**

1. Headline numbers:
   ```ruby
   st = mt4.trade_stats(from_utc: Time.now.utc - 30 * 24 * 3600)
   puts "trades #{st.trades}  PF #{st.profit_factor.round(2)}"
   ```
2. Win rate:
   ```ruby
   puts "#{mt4.trade_stats.profitability.won_trades_percent.round(1)}%"
   ```
3. Growth over the window:
   ```ruby
   puts "#{mt4.trade_stats(from_utc: Time.now.utc - 90 * 24 * 3600).growth_percent.round(1)}%"
   ```

### `trade_stats_equity_history(from_utc: nil, from: nil, exclude_same_bars: false) -> StatsWithChartsData`

*Stats + the equity/balance chart in one call (`TradeStatsEquityHistory`).*

**Usage examples:**

1. Numbers + curve:
   ```ruby
   d = mt4.trade_stats_equity_history(from_utc: Time.now.utc - 7 * 24 * 3600, exclude_same_bars: true)
   puts "trades #{d.stats.trades}  points #{d.charts.size}"
   ```
2. Open at window end:
   ```ruby
   puts mt4.trade_stats_equity_history(from_utc: Time.now.utc - 86_400).open_trades.size
   ```

### `equity_history(from_utc: nil, from: nil, exclude_same_bars: false) -> [EquityPointData]`

*Just the equity-curve points (`EquityHistory`).*

**Usage examples:**

1. Last equity:
   ```ruby
   pts = mt4.equity_history(from_utc: Time.now.utc - 7 * 24 * 3600)
   puts pts.last&.equity
   ```
2. Max drawdown on the curve:
   ```ruby
   puts (mt4.equity_history(from_utc: Time.now.utc - 30 * 24 * 3600).map(&:equity_drawdown_relative).max.to_f * 100).round(1)
   ```

### `trade_unrealized_pl(from_utc: nil, from: nil) -> [TradeUnrealizedExtremaData]`

*Per-order max/min unrealized P/L (`TradeUnrealizedPL`).*

**Usage examples:**

1. Per-order MFE/MAE:
   ```ruby
   mt4.trade_unrealized_pl(from_utc: Time.now.utc - 86_400).each do |x|
     puts "##{x.ticket} +#{x.max_unrealized_pl.round(2)} / #{x.min_unrealized_pl.round(2)}"
   end
   ```
2. Deepest adverse excursion:
   ```ruby
   w = mt4.trade_unrealized_pl(from_utc: Time.now.utc - 7 * 24 * 3600).min_by(&:min_unrealized_pl)
   puts "##{w&.ticket} #{w&.min_unrealized_pl&.round(2)}" if w
   ```
