# MT4Sugar — Symbol Information (High-Level API)

> One-liners for symbol specs and bars: digits, point, min stop, the full `SymbolSpec`, tick value, and OHLC history.

**🧩 API Layer:** **HIGH-LEVEL** — reads from [`MT4Service#symbol_params`](../MT4Service/3.%20Symbols_Quotes.md). On MT4 there is no `SymbolInfoInteger/Double` RPC, so `symbol_digits` / `symbol_point` / `min_stop_level` come from the spec struct.

**Implementation:** `lib/metarpc_mt4/mt4_sugar.rb`. **Demos:** `examples/demos/sugar/10_sugar_advanced.rb`.

[← MT4Sugar Overview](./MT4Sugar.API_Overview.md)

## 📋 All 11 methods

| Method | Returns | Description |
|--------|---------|-------------|
| **`symbol_info(symbol)`** | `SymbolSpec` / `nil` | full spec struct |
| **`all_symbols`** | `[String]` | every symbol name |
| **`symbol_available?(symbol)`** | `Boolean` | does it exist? |
| **`select_symbol(symbol, select = true)`** | `Boolean` | Market Watch toggle |
| **`symbol_digits(symbol)`** | `Integer` | price decimals |
| **`symbol_point(symbol)`** | `Float` | point size |
| **`min_stop_level(symbol)`** | `Integer` | min SL/TP distance (points) |
| **`bars(symbol, **opts)`** | `[QuoteHistoryBar]` | OHLC bars |
| **`last_bars(symbol, timeframe:, count:)`** | `[QuoteHistoryBar]` | newest N bars |
| **`tick_value_with_size(symbols)`** | `[SymbolTickValueWithSizeInfo]` | money per tick |
| **`all_symbol_specs`** | `[SymbolSpec]` | every symbol's spec |

## 🏗️ How these are built

The spec one-liners all read ONE `SymbolSpec` (from `AccountHelper.SymbolParamsMany`); the rest map to their own small RPCs:

```
sugar.symbol_digits(sym) → service.symbol_params(sym) → account.symbol_params_many → SymbolParamsMany → SymbolSpec.digits
```

* **`symbol_info` / `symbol_digits` / `symbol_point` / `min_stop_level` / `all_symbol_specs`** come from `SymbolParamsMany` (the `SymbolSpec` struct).
* **`all_symbols`** → `MarketInfo.Symbols`; **`symbol_available?`** = `all_symbols.include?`; **`select_symbol`** → `MarketInfo.SymbolSelect`.
* **`bars` / `last_bars`** → `QuoteHistory.Bars`; **`tick_value_with_size`** → `AccountHelper.TickValueWithSize`.

## 📖 Method details

### `symbol_info(symbol) -> SymbolSpec`

*Full `SymbolSpec` for a symbol (`SymbolParamsMany`).*

**Usage examples:**

1. Key spec fields:
   ```ruby
   s = mt4.symbol_info("EURUSD")
   puts "digits #{s.digits}  vol #{s.volume_min}–#{s.volume_max} step #{s.volume_step}"
   ```
2. Currencies:
   ```ruby
   s = mt4.symbol_info("EURUSD")
   puts "#{s.currency_base}/#{s.currency_profit} margin #{s.currency_margin}"
   ```
3. Round a volume:
   ```ruby
   s = mt4.symbol_info("EURUSD")
   vol = ((0.037 / s.volume_step).floor * s.volume_step).clamp(s.volume_min, s.volume_max)
   ```

### `all_symbols` · `symbol_available?(symbol)` · `select_symbol(symbol, select = true)`

**Usage examples:**

1. Count & membership:
   ```ruby
   puts "#{mt4.all_symbols.size}, has EURUSD? #{mt4.symbol_available?('EURUSD')}"
   ```
2. Add to Market Watch:
   ```ruby
   mt4.select_symbol("XAUUSD")
   ```
3. Guard an unknown symbol:
   ```ruby
   abort "no such symbol" unless mt4.symbol_available?("EURUSD")
   ```

### `symbol_digits(symbol)` · `symbol_point(symbol)` · `min_stop_level(symbol)`

**Usage examples:**

1. Digits & point:
   ```ruby
   puts "digits #{mt4.symbol_digits('EURUSD')}  point #{mt4.symbol_point('EURUSD')}"
   ```
2. Pip size:
   ```ruby
   d = mt4.symbol_digits("EURUSD")
   pip = mt4.symbol_point("EURUSD") * ((d == 3 || d == 5) ? 10 : 1)
   ```
3. Respect the stops level:
   ```ruby
   puts "min SL/TP distance: #{mt4.min_stop_level('EURUSD')} pts"
   ```

### `bars(symbol, **opts)` · `last_bars(symbol, timeframe: :M1, count: 50)`

**Usage examples:**

1. Window of bars:
   ```ruby
   mt4.bars("EURUSD", timeframe: :M5, from_utc: Time.now.to_i - 86_400).size
   ```
2. Newest 24 H1:
   ```ruby
   mt4.last_bars("EURUSD", timeframe: :H1, count: 24).each { |b| puts b.close }
   ```
3. Latest close:
   ```ruby
   puts mt4.last_bars("EURUSD", timeframe: :M5, count: 1).last&.close
   ```

### `tick_value_with_size(symbols)` · `all_symbol_specs`

**Usage examples:**

1. Money per tick:
   ```ruby
   puts mt4.tick_value_with_size("EURUSD").first.TradeTickValue
   ```
2. All specs as a lookup:
   ```ruby
   by = mt4.all_symbol_specs.to_h { |s| [s.name, s] }
   puts by["XAUUSD"]&.contract_size
   ```
