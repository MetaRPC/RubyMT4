# MT4Sugar — Risk Management (High-Level API)

> Position-sizing one-liners. ⚠️ MT4 has **no server-side margin/profit calc RPC**, so these are **local estimates** from the symbol spec + account leverage — guides, not broker-exact figures.

**🧩 API Layer:** **HIGH-LEVEL** — computed from [`symbol_info`](./9.%20Symbol_Information.md) + `account_summary.account_leverage`.

**Implementation:** `lib/metarpc_mt4/mt4_sugar.rb`. **Demos:** `examples/demos/sugar/10_sugar_advanced.rb`.

[← MT4Sugar Overview](./MT4Sugar.API_Overview.md)

---

## 📋 All 3 methods

| Method | Returns | Formula (estimate) |
|--------|---------|--------------------|
| **`required_margin(symbol, volume, price)`** | `Float` / `nil` | `volume × contract_size × price / leverage` |
| **`max_lot(symbol, price)`** | `Float` | `free_margin / required_margin(1 lot)`, floored to volume step |
| **`pip_value(symbol)`** | `Float` / `nil` | `tick_value × (pip / tick_size)` |

---

## 🏗️ How these are built

⚠️ MT4 has **no `OrderCalcMargin` / `OrderCalcProfit` RPC** (those are MT5), so these are **computed locally** from two reads — the symbol spec and the account leverage — never fetched:

```
sugar.required_margin → symbol_info (SymbolParamsMany) + account_summary.account_leverage
                      → volume × contract_size × price / leverage
```

* `required_margin` and `pip_value` are formulas over the `SymbolSpec`; `max_lot` divides `free_margin` by the per-lot margin. Treat them as **estimates** (brokers apply their own margin rules).

## 📖 Method details

### `required_margin(symbol, volume, price) -> Float`

ESTIMATED margin to open `volume` lots at `price` (leverage-based).

**Usage examples:**

1. Estimate for a trade:
   ```ruby
   puts mt4.required_margin("EURUSD", 0.10, mt4.ask("EURUSD")).round(2)
   ```
2. Afford check:
   ```ruby
   need = mt4.required_margin("EURUSD", 0.10, mt4.ask("EURUSD"))
   puts mt4.free_margin >= need ? "ok" : "too big"
   ```
3. Per-lot cost:
   ```ruby
   puts mt4.required_margin("EURUSD", 1.0, mt4.ask("EURUSD")).round(2)
   ```

### `max_lot(symbol, price) -> Float`

Largest lot that fits free margin, floored to the symbol's volume step.

**Usage examples:**

1. Biggest affordable lot:
   ```ruby
   puts mt4.max_lot("EURUSD", mt4.ask("EURUSD"))
   ```
2. Size at a fraction of the max:
   ```ruby
   vol = (mt4.max_lot("EURUSD", mt4.ask("EURUSD")) * 0.25).round(2)
   ```
3. Guard a zero:
   ```ruby
   m = mt4.max_lot("EURUSD", mt4.ask("EURUSD"))
   abort "one lot exceeds free margin" if m.zero?
   ```

### `pip_value(symbol) -> Float`

Money value of one pip per 1.0 lot.

**Usage examples:**

1. Read it:
   ```ruby
   puts mt4.pip_value("EURUSD")
   ```
2. Money risk of a stop:
   ```ruby
   stop_pips = 20
   puts (mt4.pip_value("EURUSD") * stop_pips * 0.10).round(2)   # for 0.10 lot
   ```
3. Lots for a money risk:
   ```ruby
   risk = mt4.balance * 0.01
   lots = (risk / (mt4.pip_value("EURUSD") * 20)).round(2)       # 20-pip stop
   ```
