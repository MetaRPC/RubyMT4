# MT4Sugar — Order Information (High-Level API)

> Read-only one-liners over the open book: list, filter, count, and sum. On MT4 an open market order **is** a position.

**🧩 API Layer:** **HIGH-LEVEL** — composes [`MT4Service#positions` / `#pending_orders` / `#opened_tickets`](../MT4Service/2.%20Orders_History.md).

**Implementation:** `lib/metarpc_mt4/mt4_sugar.rb`. **Demos:** `examples/demos/sugar/08_sugar_positions.rb`.

[← MT4Sugar Overview](./MT4Sugar.API_Overview.md)

## 📋 All 9 methods

| Method | Returns | Description |
|--------|---------|-------------|
| **`open_orders(magic:, symbol:)`** | `[OpenedOrderInfo]` | open **market** orders (positions) |
| **`pending(magic:, symbol:)`** | `[OpenedOrderInfo]` | pending orders |
| **`order(ticket)`** | `OpenedOrderInfo` / `nil` | one order by ticket |
| **`orders_by_symbol(symbol)`** | `[OpenedOrderInfo]` | positions on a symbol |
| **`has_order?(symbol)`** | `Boolean` | any position on a symbol? |
| **`count_orders`** | `Integer` | number of open positions |
| **`total_profit`** | `Float` | summed floating P/L |
| **`profit_by_symbol(symbol)`** | `Float` | floating P/L for a symbol |
| **`open_tickets`** | `[Integer]` | tickets (open + pending) |

---

## 🏗️ How these are built

MT4 returns ONE open-orders list; these helpers wrap that single `OpenedOrders` RPC and split/count/sum it in Ruby — only `open_tickets` is its own call:

```
sugar.open_orders → service.positions → account.opened_orders (AccountHelper.OpenedOrders)
                  → [OpenedOrderInfo] kept to market types (:OO_OP_BUY/:OO_OP_SELL)
```

* **`open_orders` / `orders_by_symbol`** = market orders filtered client-side; **`pending`** = the `*_limit` / `*_stop` types.
* **`count_orders` / `has_order?` / `total_profit` / `profit_by_symbol`** are pure Ruby over that list (no extra RPC).
* **`open_tickets`** → `service.opened_tickets` → `AccountHelper.OpenedOrdersTickets` (just the ids, cheap).

## 📖 Method details

### `open_orders(magic: nil, symbol: nil) -> [OpenedOrderInfo]`

*Open MARKET orders (= positions), filtered by magic/symbol in Ruby.*

**Usage examples:**

1. List positions:
   ```ruby
   mt4.open_orders.each { |o| puts "##{o.ticket} #{o.symbol} #{o.lots} #{o.profit.round(2)}" }
   ```
2. By strategy:
   ```ruby
   puts mt4.open_orders(magic: 600_101).size
   ```
3. By symbol:
   ```ruby
   puts mt4.open_orders(symbol: "EURUSD").size
   ```

### `pending(magic: nil, symbol: nil) -> [OpenedOrderInfo]`

*The working pending orders (the `*_limit` / `*_stop` types).*

**Usage examples:**

1. All pendings:
   ```ruby
   mt4.pending.each { |o| puts "##{o.ticket} #{o.order_type} @ #{o.open_price}" }
   ```
2. Pendings on a symbol:
   ```ruby
   puts mt4.pending(symbol: "EURUSD").size
   ```

### `order(ticket) -> OpenedOrderInfo / nil`

*One open order by ticket (market or pending) — `opened_orders.find`.*

**Usage examples:**

1. Look one up:
   ```ruby
   o = mt4.order(465_423_938)
   puts o ? "#{o.symbol} #{o.lots}" : "gone"
   ```
2. Read its SL/TP:
   ```ruby
   o = mt4.order(465_423_938)
   puts "SL #{o&.stop_loss}  TP #{o&.take_profit}"
   ```

### `orders_by_symbol(symbol)` · `has_order?(symbol)` · `count_orders`

**Usage examples:**

1. Positions on a symbol:
   ```ruby
   puts mt4.orders_by_symbol("EURUSD").size
   ```
2. Any open there?
   ```ruby
   puts mt4.has_order?("EURUSD")
   ```
3. Total open positions:
   ```ruby
   puts mt4.count_orders
   ```

### `total_profit` · `profit_by_symbol(symbol)`

**Usage examples:**

1. Whole-book floating P/L:
   ```ruby
   puts mt4.total_profit.round(2)
   ```
2. For one symbol:
   ```ruby
   puts mt4.profit_by_symbol("EURUSD").round(2)
   ```
3. Take-profit rule:
   ```ruby
   mt4.close_all_by_symbol("EURUSD") if mt4.profit_by_symbol("EURUSD") >= 50
   ```

### `open_tickets -> [Integer]`

*Just the open tickets — its own lightweight `OpenedOrdersTickets` RPC.*

**Usage examples:**

1. All tickets:
   ```ruby
   puts mt4.open_tickets.inspect
   ```
2. Count:
   ```ruby
   puts mt4.open_tickets.size
   ```
