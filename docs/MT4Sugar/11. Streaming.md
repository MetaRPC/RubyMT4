# MT4Sugar — Streaming (High-Level API)

> Real-time one-liners: tick / trade / profit / ticket / connect-state streams, plus the blocking `each_tick`.

**🧩 API Layer:** **HIGH-LEVEL** — passthroughs to [`MT4Service`](../MT4Service/5.%20Streaming_Methods.md) streams. Each returns a `Subscription` (except `each_tick`).

**Implementation:** `lib/metarpc_mt4/mt4_sugar.rb`. **Demos:** `examples/demos/lowlevel/03_streaming_methods.rb`, `service/05_service_streaming.rb`.

[← MT4Sugar Overview](./MT4Sugar.API_Overview.md)

---

## 🧵 The Subscription contract

```ruby
sub = mt4.subscribe_ticks("EURUSD") { |t| puts "#{t.bid}/#{t.ask}" }
sub.cancel          # also: sub.join, sub.alive?, sub.count, sub.error
```

> **⚠️ Never call `sub.cancel` inside the block** (deadlock). Use `each_tick` for a timed run, or cancel from the main thread. No auto-reconnect.

---

## 📋 All 6 methods

| Method | Returns | Yields |
|--------|---------|--------|
| **`subscribe_ticks(symbols, &block)`** | `Subscription` | `OnSymbolMqlTickInfo` |
| **`on_trade(&block)`** | `Subscription` | `OnTradeData` |
| **`on_opened_orders_profit(interval_ms:, &block)`** | `Subscription` | `OnOpenedOrdersProfitData` |
| **`on_tickets(interval_ms:, &block)`** | `Subscription` | `OnOpenedOrdersTicketsData` |
| **`on_connect_state(terminal_ids = nil, &block)`** | `Subscription` | `ConnectStateData` |
| **`each_tick(symbols, seconds:, &block)`** | `Integer` | (blocking; returns tick count) |

---

## 🏗️ How these are built

Each streamer forwards 1:1 to an `MT4Account` streaming RPC and returns a `Subscription` (a background thread + your block). Ticks/trades/profit/tickets live on `SubscriptionService`; connect-state on `Connection`:

```
sugar.subscribe_ticks → service.subscribe_ticks → account.on_symbol_tick → SubscriptionService.OnSymbolTick
```

* `on_trade` → `OnTrade`; `on_opened_orders_profit` → `OnOpenedOrdersProfit`; `on_tickets` → `OnOpenedOrdersTickets`; `on_connect_state` → `Connection.OnConnectState`.
* `each_tick` is the odd one out — a **blocking** wrapper that subscribes, pumps for `seconds`, cancels, and returns the count (no `Subscription` to manage).

## 📖 Method details

### `subscribe_ticks(symbols, &block) -> Subscription`

*Live ticks → `OnSymbolTick`. Returns a `Subscription`.*

**Usage examples:**

1. Several symbols for 3 s:
   ```ruby
   sub = mt4.subscribe_ticks(%w[EURUSD GBPUSD]) { |t| puts "#{t.symbol} #{t.bid}" }
   sleep 3; sub.cancel
   ```
2. Count ticks:
   ```ruby
   n = 0
   sub = mt4.subscribe_ticks("EURUSD") { |_t| n += 1 }
   sleep 2; sub.cancel
   puts n
   ```

### `on_trade(&block) -> Subscription`

*Order open / modify / close events → `OnTrade`.*

**Usage examples:**

1. Log opens & closes:
   ```ruby
   sub = mt4.on_trade do |e|
     e.event_data.new_orders.each     { |o| puts "opened ##{o.ticket}" }
     e.event_data.removed_orders.each { |o| puts "closed ##{o.ticket}" }
   end
   sleep 30; sub.cancel
   ```
2. Live equity:
   ```ruby
   sub = mt4.on_trade { |e| puts e.account_info.equity.round(2) }
   sleep 10; sub.cancel
   ```

### `on_opened_orders_profit(interval_ms: 1000, &block) -> Subscription`

*Open orders' P/L on a timer → `OnOpenedOrdersProfit`.*

**Usage examples:**

1. Live floating P/L:
   ```ruby
   sub = mt4.on_opened_orders_profit { |d| puts d.opened_orders_with_profit_updated.sum(&:order_profit).round(2) }
   sleep 10; sub.cancel
   ```
2. Slower cadence:
   ```ruby
   sub = mt4.on_opened_orders_profit(interval_ms: 3000) { |_d| }
   sleep 10; sub.cancel
   ```

### `on_tickets(interval_ms: 1000, &block) -> Subscription`

*Open ticket snapshots on a timer → `OnOpenedOrdersTickets`.*

**Usage examples:**

1. Live counts:
   ```ruby
   sub = mt4.on_tickets { |d| puts "pos #{d.position_tickets.size} / pend #{d.pending_order_tickets.size}" }
   sleep 5; sub.cancel
   ```
2. Detect opens:
   ```ruby
   prev = []
   sub = mt4.on_tickets { |d| now = d.position_tickets.to_a; (now - prev).each { |t| puts "opened ##{t}" }; prev = now }
   sleep 20; sub.cancel
   ```

### `on_connect_state(terminal_ids = nil, &block) -> Subscription`

*Terminal connect-state changes → `Connection.OnConnectState`.*

**Usage examples:**

1. Watch link health:
   ```ruby
   sub = mt4.on_connect_state { |st| puts "#{st.state} connected=#{st.is_connected}" }
   sleep 5; sub.cancel
   ```
2. Alert on disconnect:
   ```ruby
   sub = mt4.on_connect_state { |st| warn "down: #{st.error_message}" unless st.is_connected }
   sleep 30; sub.cancel
   ```

### `each_tick(symbols, seconds:, &block) -> Integer`

Blocking: subscribe, pump for `seconds`, cancel, return the tick count.

**Usage examples:**

1. Sample for 5 s:
   ```ruby
   n = mt4.each_tick("EURUSD", seconds: 5) { |t| puts "#{t.bid}/#{t.ask}" }
   puts "#{n} ticks"
   ```
2. Just count:
   ```ruby
   puts mt4.each_tick(%w[EURUSD GBPUSD], seconds: 3) { |_t| }
   ```
