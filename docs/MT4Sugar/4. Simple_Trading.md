# MT4Sugar — Simple Trading (High-Level API)

> One-liners to open orders: market buy/sell and the four pending types. MT4 has **no retcode** — a filled order returns `OrderSendData` with `ticket > 0`.

**🧩 API Layer:** **HIGH-LEVEL** — wraps [`MT4Service#order_send`](../MT4Service/4.%20Trading_Operations.md).

**Implementation:** `lib/metarpc_mt4/mt4_sugar.rb`. **Demos:** `examples/demos/sugar/07_sugar_trading.rb`.

[← MT4Sugar Overview](./MT4Sugar.API_Overview.md)

---

## 📋 All methods

| Method | Opens | Price arg |
|--------|-------|-----------|
| **`buy_market(symbol, volume, **kw)`** (alias `buy`) | market buy | — |
| **`sell_market(symbol, volume, **kw)`** (alias `sell`) | market sell | — |
| **`buy_limit(symbol, volume, price, **kw)`** | pending buy below | required |
| **`sell_limit(symbol, volume, price, **kw)`** | pending sell above | required |
| **`buy_stop(symbol, volume, price, **kw)`** | pending buy above | required |
| **`sell_stop(symbol, volume, price, **kw)`** | pending sell below | required |

> **`**kw`** forwards to `order_send`: `stop_loss:`, `take_profit:`, `comment:`, `magic:`, `slippage:`, `expiration_utc:`. All return `OrderSendData` (`ticket > 0` = filled); a rejection raises `ApiError`.

---

## 🏗️ How these are built

Every opener is the SAME RPC — `TradingHelper.OrderSend` — with a different order type:

```
sugar.buy_market(sym, vol) → service.order_send(type: :buy) → account.order_send → TradingHelper.OrderSend
```

* The **friendly** `:buy` / `:sell` / `:buy_limit` / … is mapped to the raw enum `:OC_OP_BUY` / … inside `MT4Account` (the `ORDER_TYPES` table). The raw protobuf field needs `:OC_OP_*`.
* **Market** orders omit `price` (the gateway fills at the live quote); **pending** orders (`*_limit` / `*_stop`) require it.
* All return `OrderSendData` — **`ticket > 0` = filled** (no retcode); a rejection **raises** `ApiError`.

## 📖 Method details

### `buy_market(symbol, volume, **kw)` · `sell_market(symbol, volume, **kw) -> OrderSendData`

Aliases: `buy` / `sell`.

**Usage examples:**

1. Market buy:
   ```ruby
   r = mt4.buy_market("EURUSD", 0.10, magic: 600_101)
   puts r.ticket.positive? ? "✅ ##{r.ticket}" : "❌"
   ```
2. Market sell with a comment:
   ```ruby
   mt4.sell_market("GBPUSD", 0.05, comment: "fade")
   ```
3. Alias form:
   ```ruby
   mt4.buy("EURUSD", 0.01)
   ```

### `buy_limit` · `sell_limit(symbol, volume, price, **kw) -> OrderSendData`

*Pending LIMIT below/above the market → `order_send(type: :buy_limit/:sell_limit, price:)`.*

**Usage examples:**

1. Buy-limit below the market (join a dip):
   ```ruby
   q = mt4.price("EURUSD")
   mt4.buy_limit("EURUSD", 0.10, (q.bid - 0.0050).round(5))
   ```
2. Sell-limit above (fade a rally):
   ```ruby
   q = mt4.price("EURUSD")
   mt4.sell_limit("EURUSD", 0.10, (q.ask + 0.0050).round(5))
   ```
3. With expiry:
   ```ruby
   mt4.buy_limit("EURUSD", 0.10, 1.0900, expiration_utc: Time.now.utc + 3600)
   ```

### `buy_stop` · `sell_stop(symbol, volume, price, **kw) -> OrderSendData`

*Pending STOP above/below the market → `order_send(type: :buy_stop/:sell_stop, price:)`.*

**Usage examples:**

1. Buy-stop above (breakout up):
   ```ruby
   q = mt4.price("EURUSD")
   mt4.buy_stop("EURUSD", 0.10, (q.ask + 0.0050).round(5))
   ```
2. Sell-stop below (breakdown):
   ```ruby
   q = mt4.price("EURUSD")
   mt4.sell_stop("EURUSD", 0.10, (q.bid - 0.0050).round(5))
   ```
3. Breakout bracket (both sides):
   ```ruby
   q = mt4.price("EURUSD")
   mt4.buy_stop("EURUSD", 0.10, (q.ask + 0.0050).round(5))
   mt4.sell_stop("EURUSD", 0.10, (q.bid - 0.0050).round(5))
   ```
