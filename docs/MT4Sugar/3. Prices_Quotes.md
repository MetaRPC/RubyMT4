# MT4Sugar — Prices & Quotes (High-Level API)

> One-liners for live prices — a single number, or a whole `Quote` struct.

**🧩 API Layer:** **HIGH-LEVEL** — wraps [`MT4Service#quote`](../MT4Service/3.%20Symbols_Quotes.md).

**Implementation:** `lib/metarpc_mt4/mt4_sugar.rb`. **Demos:** `examples/demos/sugar/06_sugar_basics.rb`.

[← MT4Sugar Overview](./MT4Sugar.API_Overview.md)

## 📋 All 5 methods

| Method | Returns | Description |
|--------|---------|-------------|
| **`bid(symbol)`** | `Float` | Best bid. |
| **`ask(symbol)`** | `Float` | Best ask. |
| **`spread(symbol)`** | `Float` | `ask − bid`. |
| **`price(symbol)`** | `Quote` (Struct) | `symbol, bid, ask, high, low, spread, time_utc`. |
| **`quotes(symbols)`** | `[Quote]` | Several symbols at once. |

---

## 🏗️ How these are built

Prices come from ONE RPC — `MarketInfo.Quote` (or `QuoteMany` for a batch). The readers all wrap `service.quote`, which turns the raw `QuoteData` into a tidy `Quote` struct and computes `spread` for you:

```
sugar.bid(sym) → service.quote(sym) → account.quote → MarketInfo.Quote → Quote.bid
```

* `bid` / `ask` / `spread` / `price` all read the same `Quote` struct; `spread = ask − bid` is computed when the struct is built.
* `quotes(syms)` → `service.quote_many` → `MarketInfo.QuoteMany` (one call for many symbols).

## 📖 Method details

### `bid(symbol) -> Float` · `ask(symbol) -> Float`

*Latest bid / ask — `service.quote(sym).bid` / `.ask`.*

**Usage examples:**

1. Both sides:
   ```ruby
   puts "#{mt4.bid('EURUSD')} / #{mt4.ask('EURUSD')}"
   ```
2. Mid price:
   ```ruby
   mid = (mt4.bid("EURUSD") + mt4.ask("EURUSD")) / 2
   ```
3. Entry reference for a stop:
   ```ruby
   sl = (mt4.bid("EURUSD") - 0.0020).round(5)
   ```

### `spread(symbol) -> Float`

*`ask − bid`, precomputed on the `Quote` struct.*

**Usage examples:**

1. Price units:
   ```ruby
   puts mt4.spread("EURUSD").round(5)
   ```
2. In points:
   ```ruby
   puts (mt4.spread("EURUSD") / mt4.symbol_point("EURUSD")).round
   ```
3. Skip if too wide:
   ```ruby
   next if mt4.spread("EURUSD") > 0.0003
   ```

### `price(symbol) -> Quote`

*The whole `Quote` struct in one call (symbol, bid, ask, high, low, spread, time_utc).*

**Usage examples:**

1. Snapshot:
   ```ruby
   q = mt4.price("EURUSD")
   puts "bid #{q.bid}  ask #{q.ask}  spread #{q.spread.round(5)}"
   ```
2. Session range:
   ```ruby
   q = mt4.price("EURUSD")
   puts "H #{q.high}  L #{q.low}"
   ```
3. Time of the tick:
   ```ruby
   puts Time.at(mt4.price("EURUSD").time_utc.seconds).utc.iso8601
   ```

### `quotes(symbols) -> [Quote]`

*Batched `Quote`s for several symbols — `MarketInfo.QuoteMany` in one round-trip.*

**Usage examples:**

1. Watchlist:
   ```ruby
   mt4.quotes(%w[EURUSD GBPUSD]).each { |q| puts "#{q.symbol} #{q.bid}/#{q.ask}" }
   ```
2. Index by symbol:
   ```ruby
   by = mt4.quotes(%w[EURUSD GBPUSD]).to_h { |q| [q.symbol, q] }
   puts by["EURUSD"]&.spread
   ```
