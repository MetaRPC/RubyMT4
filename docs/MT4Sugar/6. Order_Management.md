# MT4Sugar — Order Management (High-Level API)

> Close, cancel, net-out and adjust stops — the verbs you reach for after an order is open.

**🧩 API Layer:** **HIGH-LEVEL** — composes [`MT4Service`](../MT4Service/4.%20Trading_Operations.md) close/modify methods.

**Implementation:** `lib/metarpc_mt4/mt4_sugar.rb`. **Demos:** `examples/demos/sugar/07_sugar_trading.rb`, `orchestrators/11_trailing_stop.rb`, `orchestrators/13_grid_trader.rb`.

## 📋 All 9 methods

| Method | Does |
|--------|------|
| **`close_order(ticket, lots: nil, slippage: 10)`** | close a market order (full / partial) |
| **`close_all(slippage: 10)`** | close every open market order |
| **`close_all_by_symbol(symbol, slippage: 10)`** | close all market orders on a symbol |
| **`cancel_order(ticket)`** | delete a pending order |
| **`cancel_all_pending`** | delete every pending order |
| **`close_by(ticket, opposite_ticket)`** | net out two opposite orders |
| **`modify_sl(ticket, stop_loss)`** | set the stop-loss |
| **`modify_tp(ticket, take_profit)`** | set the take-profit |
| **`modify_sl_tp(ticket, stop_loss:, take_profit:)`** | set both |

---

## 🏗️ How these are built

Single-ticket actions are one RPC; the "all" / "by-symbol" helpers are **Ruby loops** over the open-orders list, not a bulk server call:

```
sugar.close_order(t) → service.order_close(ticket: t) → TradingHelper.OrderCloseDelete
sugar.close_all      → open_orders.map { |o| close_order(o.ticket) }   # a loop of closes
```

* **`close_order` / `cancel_order`** → `OrderCloseDelete` (close a market order / delete a pending). **`close_by`** → `OrderCloseBy`. **`modify_sl` / `modify_tp` / `modify_sl_tp`** → `OrderModify`.
* **`close_all` / `close_all_by_symbol` / `cancel_all_pending`** iterate the matching orders and close each — N calls; guard each with `rescue` if a ticket may already be gone.

## 📖 Method details

### `close_order(ticket, lots: nil, slippage: 10) -> OrderCloseDeleteData`

*Close a market order (full or partial) by ticket → `OrderCloseDelete`.*

**Usage examples:**

1. Full close:
   ```ruby
   mt4.close_order(465_423_938)
   ```
2. Partial close:
   ```ruby
   mt4.close_order(465_423_938, lots: 0.05)
   ```
3. Close the newest position on a symbol:
   ```ruby
   o = mt4.open_orders(symbol: "EURUSD").max_by(&:ticket)
   mt4.close_order(o.ticket) if o
   ```

### `close_all(slippage: 10) -> Array`

*Loop: close every open market order (one `OrderCloseDelete` each).*

**Usage examples:**

1. Flatten everything:
   ```ruby
   mt4.close_all
   ```
2. Equity-stop kill switch:
   ```ruby
   mt4.close_all if mt4.equity < mt4.balance * 0.9
   ```
3. Count what closed:
   ```ruby
   puts "closed #{mt4.close_all.size}"
   ```

### `close_all_by_symbol(symbol, slippage: 10) -> Array`

*Loop: close every market order on one symbol.*

**Usage examples:**

1. Flatten one symbol:
   ```ruby
   mt4.close_all_by_symbol("EURUSD")
   ```
2. Only if in profit there:
   ```ruby
   mt4.close_all_by_symbol("EURUSD") if mt4.profit_by_symbol("EURUSD") > 0
   ```

### `cancel_order(ticket)` · `cancel_all_pending -> Array`

**Usage examples:**

1. Delete one pending:
   ```ruby
   mt4.cancel_order(465_424_047)
   ```
2. Delete every pending:
   ```ruby
   mt4.cancel_all_pending
   ```
3. Cancel pendings on a symbol:
   ```ruby
   mt4.pending(symbol: "EURUSD").each { |o| mt4.cancel_order(o.ticket) }
   ```

### `close_by(ticket, opposite_ticket) -> OrderCloseByData`

*Net out two opposite market orders in a single call → `OrderCloseBy`.*

**Usage examples:**

1. Net out a buy and a sell:
   ```ruby
   mt4.close_by(buy_ticket, sell_ticket)
   ```
2. Find the opposite automatically:
   ```ruby
   o = mt4.open_orders(symbol: "EURUSD")
   b = o.find { |x| x.order_type == :OO_OP_BUY }; s = o.find { |x| x.order_type == :OO_OP_SELL }
   mt4.close_by(b.ticket, s.ticket) if b && s
   ```

### `modify_sl(ticket, stop_loss)` · `modify_tp(ticket, take_profit)` · `modify_sl_tp(ticket, stop_loss:, take_profit:)`

**Usage examples:**

1. Set a stop:
   ```ruby
   mt4.modify_sl(465_423_938, 1.0800)
   ```
2. Set a target:
   ```ruby
   mt4.modify_tp(465_423_938, 1.1000)
   ```
3. Both at once:
   ```ruby
   mt4.modify_sl_tp(465_423_938, stop_loss: 1.0800, take_profit: 1.1000)
   ```
