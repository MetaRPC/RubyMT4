# MT4Sugar — Trading with SL/TP (High-Level API)

> Open with protective stops in one call, plus the raw `order_send` / `order_modify` / `order_close` passthroughs for full control.

**🧩 API Layer:** **HIGH-LEVEL** — wraps [`MT4Service`](../MT4Service/4.%20Trading_Operations.md) trade methods.

**Implementation:** `lib/metarpc_mt4/mt4_sugar.rb`. **Demos:** `examples/demos/sugar/07_sugar_trading.rb`.

[← MT4Sugar Overview](./MT4Sugar.API_Overview.md)

## 📋 All 5 methods

| Method | Returns | Description |
|--------|---------|-------------|
| **`buy_market_with_sl_tp(symbol, volume, sl:, tp:, **kw)`** | `OrderSendData` | market buy + SL/TP in one call |
| **`sell_market_with_sl_tp(symbol, volume, sl:, tp:, **kw)`** | `OrderSendData` | market sell + SL/TP |
| **`order_send(symbol:, type:, volume:, **opts)`** | `OrderSendData` | full-control passthrough |
| **`order_modify(ticket:, **opts)`** | `OrderModifyData` | change SL/TP/price/expiration |
| **`order_close(ticket:, **opts)`** | `OrderCloseDeleteData` | close / delete by ticket |

---

## 🏗️ How these are built

The SL/TP openers are just `order_send` with the stop fields filled; the raw passthroughs forward 1:1 to the trade RPCs:

```
sugar.buy_market_with_sl_tp → service.order_send(type: :buy, stop_loss:, take_profit:) → TradingHelper.OrderSend
sugar.order_modify          → service.order_modify  → TradingHelper.OrderModify
sugar.order_close           → service.order_close   → TradingHelper.OrderCloseDelete
```

* No extra RPC for SL/TP — the same `OrderSend` carries the `stoploss` / `takeprofit` fields.
* `order_send` / `order_modify` / `order_close` are escape hatches for full control (any `type:` / option).

## 📖 Method details

### `buy_market_with_sl_tp(symbol, volume, sl:, tp:, **kw) -> OrderSendData`

*Market buy + protective SL/TP in one `OrderSend`.*

**Usage examples:**

1. Buy with fixed SL/TP:
   ```ruby
   q = mt4.price("EURUSD")
   mt4.buy_market_with_sl_tp("EURUSD", 0.10, sl: (q.bid - 0.0020).round(5), tp: (q.ask + 0.0020).round(5))
   ```
2. Risk/reward by pips:
   ```ruby
   pip = mt4.symbol_point("EURUSD") * 10
   q = mt4.price("EURUSD")
   mt4.buy_market_with_sl_tp("EURUSD", 0.10, sl: (q.bid - 20 * pip).round(5), tp: (q.ask + 40 * pip).round(5))
   ```
3. With magic:
   ```ruby
   mt4.buy_market_with_sl_tp("EURUSD", 0.10, sl: 1.08, tp: 1.10, magic: 700_008)
   ```

### `sell_market_with_sl_tp(symbol, volume, sl:, tp:, **kw) -> OrderSendData`

*The sell mirror of the above.*

**Usage examples:**

1. Sell with SL above / TP below:
   ```ruby
   q = mt4.price("EURUSD")
   mt4.sell_market_with_sl_tp("EURUSD", 0.10, sl: (q.ask + 0.0020).round(5), tp: (q.bid - 0.0020).round(5))
   ```
2. By pips:
   ```ruby
   pip = mt4.symbol_point("EURUSD") * 10
   q = mt4.price("EURUSD")
   mt4.sell_market_with_sl_tp("EURUSD", 0.10, sl: (q.ask + 20 * pip).round(5), tp: (q.bid - 40 * pip).round(5))
   ```

### `order_send(symbol:, type:, volume:, **opts) -> OrderSendData`

Full-control passthrough (any `type:` / option).

**Usage examples:**

1. Pending with everything:
   ```ruby
   mt4.order_send(symbol: "EURUSD", type: :buy_stop, volume: 0.1, price: 1.10,
                  stop_loss: 1.095, take_profit: 1.11, magic: 42, comment: "brk")
   ```
2. Market with slippage:
   ```ruby
   mt4.order_send(symbol: "EURUSD", type: :buy, volume: 0.1, slippage: 5)
   ```

### `order_modify(ticket:, **opts) -> OrderModifyData`

**Usage examples:**

1. Set SL/TP:
   ```ruby
   mt4.order_modify(ticket: 465_423_938, stop_loss: 1.08, take_profit: 1.10)
   ```
2. Re-price a pending:
   ```ruby
   mt4.order_modify(ticket: 465_424_047, price: 1.0950)
   ```

### `order_close(ticket:, **opts) -> OrderCloseDeleteData`

**Usage examples:**

1. Full close:
   ```ruby
   mt4.order_close(ticket: 465_423_938)
   ```
2. Partial:
   ```ruby
   mt4.order_close(ticket: 465_423_938, lots: 0.05)
   ```
