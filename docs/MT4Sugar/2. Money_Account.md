# MT4Sugar — Money & Account (High-Level API)

> One-liners for the money numbers and account snapshot. MT4 has no `AccountInfoDouble` RPC, so each read comes from **one `AccountSummary`** call.

**🧩 API Layer:** **HIGH-LEVEL** — reads fields off [`MT4Service#account_summary`](../MT4Service/1.%20Account_Information.md).

**Implementation:** `lib/metarpc_mt4/mt4_sugar.rb`. **Demos:** `examples/demos/sugar/06_sugar_basics.rb`.

## 🏗️ How these are built

MT4 has **no `AccountInfoDouble` RPC** (that's an MT5 feature), so the money one-liners don't each call the server — they all read a field off **one** `AccountSummary` read:

```
sugar.balance → service.account_summary → account.account_summary
              → AccountHelper.AccountSummary RPC → AccountSummaryData.account_balance
```

* **`balance` / `equity` / `margin` / `free_margin` / `margin_level` / `credit`** — a direct field off `AccountSummaryData` (fetch the summary once, read many fields).
* **`profit`** — **computed** in Ruby as `equity − balance − credit`; MT4 has no floating-P/L field.
* **`account_info`** — the same summary, repackaged into a tidy `Account` struct.
* **`demo?`** — `account_summary.account_trade_mode == :ACCOUNT_TRADE_MODE_DEMO`.
* **`accounts` / `server_timezone`** — their own small RPCs (`Accounts.List` / `ServerTimezone`), not part of the summary.

## 📖 Method details

> Each heading below notes **what it is** and **how it's built**, then shows usage.

### `balance -> Float`

*Realized balance (excludes floating P/L). Reads `AccountSummaryData.account_balance`.*

**Usage examples:**

1. Print it:
   ```ruby
   puts mt4.balance.round(2)
   ```
2. Empty-account guard:
   ```ruby
   abort "no funds" if mt4.balance <= 0
   ```
3. Risk budget (1% of balance):
   ```ruby
   risk = mt4.balance * 0.01
   ```

### `equity -> Float`

*Balance + credit + floating P/L — the live account value. Reads `account_equity`.*

**Usage examples:**

1. Print it:
   ```ruby
   puts mt4.equity.round(2)
   ```
2. Equity-stop trigger:
   ```ruby
   mt4.close_all if mt4.equity < mt4.balance * 0.9
   ```
3. Utilisation vs balance:
   ```ruby
   puts "#{(100 * mt4.equity / mt4.balance).round(1)}%"
   ```

### `margin -> Float` · `free_margin -> Float`

*Margin locked by open orders, and what's free to open more. Reads `account_margin` / `account_margin_free`.*

**Usage examples:**

1. Used / free:
   ```ruby
   puts "used #{mt4.margin.round(2)}  free #{mt4.free_margin.round(2)}"
   ```
2. Can I afford this trade?
   ```ruby
   need = mt4.required_margin("EURUSD", 0.1, mt4.ask("EURUSD"))
   puts mt4.free_margin >= need ? "ok" : "too big"
   ```
3. In market by margin?
   ```ruby
   puts mt4.margin.zero? ? "flat" : "in market"
   ```

### `margin_level -> Float`

*`equity / margin × 100`, in percent (0 when flat). Reads `account_margin_level`.*

**Usage examples:**

1. Percent:
   ```ruby
   puts "#{mt4.margin_level.round(1)}%"
   ```
2. Health gauge:
   ```ruby
   lvl = mt4.margin_level
   puts lvl.zero? ? "flat" : (lvl < 200 ? "⚠️ low" : "✅ healthy")
   ```
3. Margin-call watch:
   ```ruby
   warn "near margin call!" if mt4.margin_level.positive? && mt4.margin_level < 120
   ```

### `credit -> Float` · `profit -> Float`

*`credit` reads `account_credit`; `profit` is **computed** by sugar as `equity − balance − credit` (MT4 has no floating-P/L field).*

**Usage examples:**

1. Floating profit:
   ```ruby
   puts mt4.profit.round(2)
   ```
2. In profit?
   ```ruby
   puts mt4.profit.positive? ? "green" : "red"
   ```
3. Take-profit on the whole book:
   ```ruby
   mt4.close_all if mt4.profit >= 100
   ```

### `account_info -> Account`

*The same `AccountSummary` read, repackaged into a tidy `Account` struct (login, balance, equity, currency, leverage, trade_mode, company, server_time_utc).*

**Usage examples:**

1. Status line:
   ```ruby
   a = mt4.account_info
   puts "##{a.login} · #{a.balance} #{a.currency} · 1:#{a.leverage}"
   ```
2. Broker & mode:
   ```ruby
   a = mt4.account_info
   puts "#{a.company} (#{a.trade_mode})"
   ```

### `account_summary -> AccountSummaryData`

*The raw protobuf `AccountSummaryData` — every field — when the `Account` struct isn't enough. This is the one call the money helpers above all read from.*

**Usage examples:**

1. Full margin picture:
   ```ruby
   s = mt4.account_summary
   puts "used #{s.account_margin}  free #{s.account_margin_free}  level #{s.account_margin_level}%"
   ```
2. Trade flags:
   ```ruby
   s = mt4.account_summary
   puts "trade allowed? #{s.account_trade_allowed}  EA? #{s.account_trade_expert}"
   ```

### `demo? -> Boolean`

*True on a demo account — checks `account_summary.account_trade_mode == :ACCOUNT_TRADE_MODE_DEMO`.*

**Usage examples:**

1. Refuse real:
   ```ruby
   abort "demo only" unless mt4.demo?
   ```
2. Size by mode:
   ```ruby
   vol = mt4.demo? ? 0.10 : 0.01
   ```

### `accounts(**opts) -> Array` · `server_timezone -> ServerTimezoneData`

*Their own small RPCs (not part of the summary): `accounts` → `Accounts.List` (terminals on this key, auto-paged); `server_timezone` → `ServerTimezone` (broker UTC offset).*

**Usage examples:**

1. Terminals on this key:
   ```ruby
   puts mt4.accounts.size
   ```
2. Broker clock offset:
   ```ruby
   tz = mt4.server_timezone
   puts "#{tz.server}: #{tz.utc_offset_seconds}s"
   ```
