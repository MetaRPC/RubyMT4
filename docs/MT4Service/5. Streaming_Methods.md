# MT4Service — Streaming Methods (Mid-Level API)

> 6 methods for real-time data: tick / trade / profit / ticket / connect-state streams, plus a blocking `each_tick` convenience.

**🧩 API Layer:** **MID-LEVEL** — friendly passthroughs to [`MT4Account`](../MT4Account/5.%20Streaming_Methods/Streaming_Methods.Overview.md)'s streaming RPCs, each returning a `Subscription`.

**Implementation:** `lib/metarpc_mt4/mt4_service.rb`, wrapping `on_symbol_tick` / `on_trade` / `on_opened_orders_profit` / `on_opened_orders_tickets` / `on_connect_state` on `MT4Account`.

**Demos:** `examples/demos/service/05_service_streaming.rb`.

## 🧵 The Subscription contract

Every streaming method (except the blocking `each_tick`) returns a `MetaRPC::MT4::Subscription`:

```ruby
sub = service.subscribe_ticks("EURUSD") { |q| puts "#{q.bid}/#{q.ask}" }
# … runs on a background thread …
sub.cancel      # stop cleanly (also: sub.join, sub.alive?, sub.count, sub.error)
```

> **⚠️ Never call `sub.cancel` from inside the block** — it deadlocks on its own reader thread. Use `each_tick` for a simple timed run, or set a flag and cancel from the main thread. No auto-reconnect: on a drop, `sub.error` is set.

## 📋 All 6 methods

| Method | Returns | Low-level equivalent |
|--------|---------|----------------------|
| **`subscribe_ticks(symbols, &block)`** | `Subscription` | `on_symbol_tick` |
| **`on_trade(&block)`** | `Subscription` | `on_trade` |
| **`on_opened_orders_profit(interval_ms:, &block)`** | `Subscription` | `on_opened_orders_profit` |
| **`on_tickets(interval_ms:, &block)`** | `Subscription` | `on_opened_orders_tickets` |
| **`on_connect_state(terminal_ids = nil, &block)`** | `Subscription` | `on_connect_state` (defaults to this terminal) |
| **`each_tick(symbols, seconds:, &block)`** | `Integer` (tick count) | `on_symbol_tick` + sleep + cancel |

## 📖 Method details

### `subscribe_ticks(symbols, &block) -> Subscription`

Live ticks (yields `OnSymbolMqlTickInfo`).

**Usage examples:**

1. Several symbols for 3 s:
   ```ruby
   sub = service.subscribe_ticks(%w[EURUSD GBPUSD]) { |t| puts "#{t.symbol} #{t.bid}" }
   sleep 3
   sub.cancel
   ```
2. Count ticks:
   ```ruby
   n = 0
   sub = service.subscribe_ticks("EURUSD") { |_t| n += 1 }
   sleep 2; sub.cancel
   puts "#{n} ticks (#{sub.count} total)"
   ```

### `on_trade(&block) -> Subscription`

Fires on order open / update / close (yields `OnTradeData`).

**Usage examples:**

1. Log opens & closes:
   ```ruby
   sub = service.on_trade do |e|
     e.event_data.new_orders.each     { |o| puts "opened ##{o.ticket}" }
     e.event_data.removed_orders.each { |o| puts "closed ##{o.ticket}" }
   end
   sleep 30
   sub.cancel
   ```
2. Live equity from events:
   ```ruby
   sub = service.on_trade { |e| puts "equity #{e.account_info.equity.round(2)}" }
   sleep 10; sub.cancel
   ```

### `on_opened_orders_profit(interval_ms: 1000, &block) -> Subscription`

Open orders' floating P/L on a timer (yields `OnOpenedOrdersProfitData`).

**Usage examples:**

1. Live total floating P/L:
   ```ruby
   sub = service.on_opened_orders_profit(interval_ms: 1000) do |d|
     puts "floating #{d.opened_orders_with_profit_updated.sum(&:order_profit).round(2)}"
   end
   sleep 10
   sub.cancel
   ```
2. Per-order rows:
   ```ruby
   sub = service.on_opened_orders_profit do |d|
     d.opened_orders_with_profit_updated.each { |o| puts "##{o.ticket} #{o.order_profit.round(2)}" }
   end
   sleep 5; sub.cancel
   ```

### `on_tickets(interval_ms: 1000, &block) -> Subscription`

Open ticket snapshots on a timer (yields `OnOpenedOrdersTicketsData` with `position_tickets` / `pending_order_tickets`).

**Usage examples:**

1. Live counts:
   ```ruby
   sub = service.on_tickets { |d| puts "pos #{d.position_tickets.size} / pend #{d.pending_order_tickets.size}" }
   sleep 5
   sub.cancel
   ```
2. Detect opens/closes:
   ```ruby
   prev = []
   sub = service.on_tickets do |d|
     now = d.position_tickets.to_a
     (now - prev).each { |t| puts "opened ##{t}" }; prev = now
   end
   sleep 20; sub.cancel
   ```

### `on_connect_state(terminal_ids = nil, &block) -> Subscription`

Terminal connect-state changes (yields `ConnectStateData`). Defaults to this client's terminal.

**Usage examples:**

1. Watch link health:
   ```ruby
   sub = service.on_connect_state { |st| puts "#{st.state} connected=#{st.is_connected}" }
   sleep 5
   sub.cancel
   ```
2. Alert on disconnect:
   ```ruby
   sub = service.on_connect_state { |st| warn "down: #{st.error_message}" unless st.is_connected }
   sleep 30; sub.cancel
   ```

### `each_tick(symbols, seconds:, &block) -> Integer`

Blocking convenience: subscribe, pump the block for `seconds`, cancel cleanly, return the tick count.

**Usage examples:**

1. Sample for 5 s:
   ```ruby
   n = service.each_tick("EURUSD", seconds: 5) { |t| puts "#{t.bid}/#{t.ask}" }
   puts "#{n} ticks"
   ```
2. Just count, no printing:
   ```ruby
   puts service.each_tick(%w[EURUSD GBPUSD], seconds: 3) { |_t| }
   ```
