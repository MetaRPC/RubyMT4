# MT4Service — Account & Stats (Mid-Level API)

> 9 methods for reading account state and performance — a typed snapshot, the raw summary, demo check, terminal list, server time zone, and the four trade-statistics reads.

**🧩 API Layer:** **MID-LEVEL** — a friendly facade over [`MT4Account`](../MT4Account/1.%20Account_Information/Account_Information.Overview.md) that returns a typed `Account` Struct and passes the stats through.

**Implementation:** `lib/metarpc_mt4/mt4_service.rb`, wrapping `account_summary` / `accounts` / `server_timezone` / `trade_stats*` / `equity_history` / `trade_unrealized_pl` on `MT4Account`.

**Demos:** `examples/demos/service/04_service_demo.rb`, `sugar/09_sugar_history.rb`.

## 📋 All 9 methods

| Method | Returns | Low-level equivalent |
|--------|---------|----------------------|
| **`account_info`** | `Account` (Struct) | `account_summary`, composed |
| **`account_summary`** | `AccountSummaryData` | `account_summary` (raw passthrough) |
| **`demo?`** | `Boolean` | `account_summary.account_trade_mode == :ACCOUNT_TRADE_MODE_DEMO` |
| **`accounts(include_stopped:, page_size:)`** | `Array` | `accounts` (terminal list) |
| **`server_timezone`** | `ServerTimezoneData` | `server_timezone` |
| **`trade_stats(from_utc:, from:)`** | `StatsData` | `trade_stats` |
| **`trade_stats_equity_history(from_utc:, from:, exclude_same_bars:)`** | `StatsWithChartsData` | `trade_stats_equity_history` |
| **`equity_history(from_utc:, from:, exclude_same_bars:)`** | `[EquityPointData]` | `equity_history` |
| **`trade_unrealized_pl(from_utc:, from:)`** | `[TradeUnrealizedExtremaData]` | `trade_unrealized_pl` |

## 📦 `Account` (Struct)

Returned by `account_info`:

| Field | Type | Description |
| ----- | ---- | ----------- |
| `login` | `Integer` | Account number. |
| `balance` | `Float` | Balance (without floating P&L). |
| `equity` | `Float` | Equity (balance + credit + floating P&L). |
| `currency` | `String` | Deposit currency. |
| `leverage` | `Integer` | Leverage (100 = 1:100). |
| `trade_mode` | `Symbol` | `:ACCOUNT_TRADE_MODE_DEMO` / `_CONTEST` / `_REAL`. |
| `company` | `String` | Broker name. |
| `server_time_utc` | `Timestamp` | Broker server time in UTC (read `.seconds`). |

## 📖 Method details

### `account_info -> Account`

The account as one typed Struct.

**Usage examples:**

1. One-line status:
   ```ruby
   a = service.account_info
   puts "##{a.login} on #{a.company} · #{a.balance} #{a.currency} · 1:#{a.leverage}"
   ```
2. Floating P&L (MT4: equity − balance − credit):
   ```ruby
   s = service.account_summary
   puts "floating: #{(s.account_equity - s.account_balance - s.account_credit).round(2)}"
   ```
3. Guard before a run:
   ```ruby
   abort "empty account" if service.account_info.balance <= 0
   ```

### `account_summary -> AccountSummaryData`

The full raw summary (every field, including all margin fields) when the Struct isn't enough.

**Usage examples:**

1. Margin picture:
   ```ruby
   s = service.account_summary
   puts "used #{s.account_margin}  free #{s.account_margin_free}  level #{s.account_margin_level}%"
   ```
2. Terminal / trade flags:
   ```ruby
   s = service.account_summary
   puts "trade allowed? #{s.account_trade_allowed}  EA allowed? #{s.account_trade_expert}"
   ```
3. Credit & investor mode:
   ```ruby
   s = service.account_summary
   puts "credit #{s.account_credit}  investor? #{s.is_investor}"
   ```

### `demo? -> Boolean`

**Usage examples:**

1. Refuse to trade on a real account:
   ```ruby
   abort "refusing to trade on a REAL account" unless service.demo?
   ```
2. Branch behaviour by mode:
   ```ruby
   volume = service.demo? ? 0.10 : 0.01
   ```
3. Log the mode once at startup:
   ```ruby
   puts "mode: #{service.demo? ? 'DEMO' : 'LIVE'}"
   ```

### `accounts(include_stopped: false, page_size: 200) -> Array`

The terminals owned by this API key (auto-paged).

**Usage examples:**

1. How many terminals:
   ```ruby
   puts "terminals on this key: #{service.accounts.size}"
   ```
2. Include stopped ones:
   ```ruby
   all = service.accounts(include_stopped: true)
   puts "including stopped: #{all.size}"
   ```
3. List their ids:
   ```ruby
   service.accounts.each { |t| puts t.id rescue nil }
   ```

### `server_timezone -> ServerTimezoneData`

The broker's UTC offset, for converting `*_utc` timestamps.

**Usage examples:**

1. Print the offset:
   ```ruby
   tz = service.server_timezone
   puts "#{tz.server}: offset #{tz.utc_offset_seconds}s (#{tz.source})"
   ```
2. Offset in hours:
   ```ruby
   h = service.server_timezone.utc_offset_seconds / 3600.0
   puts "UTC#{h >= 0 ? '+' : ''}#{h}"
   ```
3. Is the value fresh?
   ```ruby
   puts service.server_timezone.source == :SERVER_TIMEZONE_SOURCE_LIVE ? "live" : "cached"
   ```

### `trade_stats(from_utc: nil, from: nil) -> StatsData`

Aggregate statistics since a start time (pass `from_utc` **or** `from`; omit for full history).

**Usage examples:**

1. Headline numbers:
   ```ruby
   st = service.trade_stats(from_utc: Time.now.utc - 30 * 24 * 3600)
   puts "trades #{st.trades}  PF #{st.profit_factor.round(2)}  total #{st.summary.total_profit.round(2)}"
   ```
2. Win/loss split:
   ```ruby
   p = service.trade_stats.profitability
   puts "won #{p.won_trades_percent.round(1)}% / lost #{p.lost_trades_percent.round(1)}%"
   ```
3. Drawdown guard:
   ```ruby
   st = service.trade_stats
   warn "deep drawdown!" if st.max_equity_drawdown_relative > 0.3
   ```

### `trade_stats_equity_history(from_utc: nil, from: nil, exclude_same_bars: false) -> StatsWithChartsData`

Stats **plus** the equity/balance chart in one call.

**Usage examples:**

1. Numbers + curve:
   ```ruby
   d = service.trade_stats_equity_history(from_utc: Time.now.utc - 7 * 24 * 3600, exclude_same_bars: true)
   puts "trades #{d.stats.trades}  chart points #{d.charts.size}"
   ```
2. Still-open trades at window end:
   ```ruby
   puts "open at end: #{service.trade_stats_equity_history(from_utc: Time.now.utc - 86_400).open_trades.size}"
   ```
3. Trade series size:
   ```ruby
   puts service.trade_stats_equity_history(from_utc: Time.now.utc - 86_400).trades.size
   ```

### `equity_history(from_utc: nil, from: nil, exclude_same_bars: false) -> [EquityPointData]`

Just the equity-curve points.

**Usage examples:**

1. Count & last equity:
   ```ruby
   pts = service.equity_history(from_utc: Time.now.utc - 7 * 24 * 3600)
   puts "#{pts.size} points, last equity #{pts.last&.equity}"
   ```
2. Worst drawdown on the curve:
   ```ruby
   worst = service.equity_history(from_utc: Time.now.utc - 30 * 24 * 3600).map(&:equity_drawdown_relative).max || 0.0
   puts "#{(worst * 100).round(1)}%"
   ```
3. Export rows:
   ```ruby
   service.equity_history(from_utc: Time.now.utc - 86_400).each { |p| puts [p.balance, p.equity].inspect }
   ```

### `trade_unrealized_pl(from_utc: nil, from: nil) -> [TradeUnrealizedExtremaData]`

Per-order max/min unrealized P/L (MFE/MAE).

**Usage examples:**

1. List extrema:
   ```ruby
   service.trade_unrealized_pl(from_utc: Time.now.utc - 86_400).each do |x|
     puts "##{x.ticket} #{x.symbol}: MFE +#{x.max_unrealized_pl.round(2)} / MAE #{x.min_unrealized_pl.round(2)}"
   end
   ```
2. Deepest adverse excursion:
   ```ruby
   worst = service.trade_unrealized_pl(from_utc: Time.now.utc - 7 * 24 * 3600).min_by(&:min_unrealized_pl)
   puts "##{worst&.ticket} #{worst&.min_unrealized_pl&.round(2)}" if worst
   ```
3. Count rows:
   ```ruby
   puts service.trade_unrealized_pl(from_utc: Time.now.utc - 86_400).size
   ```

> **Window bounds are strings.** The stats methods send `from_utc` / `from` as ISO-8601 — the SDK converts a Ruby `Time` for you. See the low-level pages for the full field tables.
