# MT4Service — Trading Operations (Mid-Level API)

> 6 methods to trade with plain arguments: send a market/pending order, the `buy`/`sell` shortcuts, modify, close/delete, and close-by.

**🧩 API Layer:** **MID-LEVEL** — a thin, friendly passthrough to [`MT4Account`](../MT4Account/4.%20Trading_Operations/Trading_Operations.Overview.md)'s trade RPCs.

**Implementation:** `lib/metarpc_mt4/mt4_service.rb`, wrapping `order_send` / `order_modify` / `order_close` / `order_close_by` on `MT4Account`.

**Demos:** `examples/demos/service/04_service_demo.rb`, `sugar/07_sugar_trading.rb`.

## ⚠️ MT4 trade contract

* **No retcode.** `order_send` returns `OrderSendData` with a **`ticket > 0` when filled**. A rejection **raises** `MetaRPC::MT4::ApiError` — read `e.mql_code` (130 invalid stops · 132 market closed · 134 no money · 138 requote).
* **Friendly types.** `type:` accepts `:buy :sell :buy_limit :sell_limit :buy_stop :sell_stop` (mapped to `OC_OP_*`).
* **Exactly once.** A transport failure after the request may have reached the terminal raises `TradeOutcomeUnknown` — never auto-retried.

## 📋 All 6 methods

| Method | Returns | Low-level equivalent |
|--------|---------|----------------------|
| **`order_send(symbol:, type:, volume:, **opts)`** | `OrderSendData` | `order_send` |
| **`buy(symbol, volume, **opts)`** | `OrderSendData` | `order_send(type: :buy)` |
| **`sell(symbol, volume, **opts)`** | `OrderSendData` | `order_send(type: :sell)` |
| **`order_modify(ticket:, **opts)`** | `OrderModifyData` | `order_modify` |
| **`order_close(ticket:, lots:, price:, slippage:)`** | `OrderCloseDeleteData` | `order_close` (close / delete) |
| **`order_close_by(ticket:, opposite_ticket:)`** | `OrderCloseByData` | `order_close_by` |

> **`order_send` options** (`**opts`): `price:`, `stop_loss:`, `take_profit:`, `comment:`, `magic:`, `slippage:`, `expiration_utc:`. **`order_modify` options:** `stop_loss:`, `take_profit:`, `price:`, `expiration_utc:`.

## 📖 Method details

### `order_send(symbol:, type:, volume:, **opts) -> OrderSendData`

1. Market buy:
   ```ruby
   r = service.order_send(symbol: "EURUSD", type: :buy, volume: 0.10, magic: 600_101)
   puts "ticket ##{r.ticket} @ #{r.price}"
   ```
2. With SL/TP:
   ```ruby
   q = service.quote("EURUSD")
   service.order_send(symbol: "EURUSD", type: :buy, volume: 0.10,
                      stop_loss: (q.bid - 0.0020).round(5), take_profit: (q.ask + 0.0020).round(5))
   ```
3. Pending buy-limit:
   ```ruby
   q = service.quote("EURUSD")
   service.order_send(symbol: "EURUSD", type: :buy_limit, volume: 0.10, price: (q.bid - 0.0050).round(5))
   ```

### `buy(symbol, volume, **opts)` · `sell(symbol, volume, **opts) -> OrderSendData`

Positional-symbol market shortcuts.

**Usage examples:**

1. Quick buy:
   ```ruby
   r = service.buy("EURUSD", 0.10, comment: "quick")
   puts "##{r.ticket}"
   ```
2. Quick sell:
   ```ruby
   service.sell("GBPUSD", 0.05)
   ```
3. With magic + SL:
   ```ruby
   service.buy("EURUSD", 0.10, magic: 600_101, stop_loss: service.quote("EURUSD").bid - 0.0020)
   ```

### `order_modify(ticket:, **opts) -> OrderModifyData`

**Usage examples:**

1. Set SL/TP:
   ```ruby
   service.order_modify(ticket: 465_423_938, stop_loss: 1.0800, take_profit: 1.1000)
   ```
2. Move to break-even:
   ```ruby
   o = service.opened_orders.find { |x| x.ticket == 465_423_938 }
   service.order_modify(ticket: o.ticket, stop_loss: o.open_price) if o
   ```
3. Re-price a pending:
   ```ruby
   service.order_modify(ticket: 465_424_047, price: 1.0950)
   ```

### `order_close(ticket:, lots: nil, price: nil, slippage: 10) -> OrderCloseDeleteData`

Close a market order (full / partial) or delete a pending one.

1. Full close:
   ```ruby
   out = service.order_close(ticket: 465_423_938)
   puts "closed (#{out.mode})"            # OCD_MARKET_ORDER
   ```
2. Partial close:
   ```ruby
   service.order_close(ticket: 465_423_938, lots: 0.05)
   ```
3. Delete a pending:
   ```ruby
   service.order_close(ticket: 465_424_047)   # OCD_PENDING_ORDER
   ```

### `order_close_by(ticket:, opposite_ticket:) -> OrderCloseByData`

Net out two opposite market orders on the same symbol.

**Usage examples:**

1. Close a hedge:
   ```ruby
   out = service.order_close_by(ticket: buy_ticket, opposite_ticket: sell_ticket)
   puts "closed by @ #{out.close_price}, P/L #{out.profit.round(2)}"
   ```
2. Find the opposite automatically:
   ```ruby
   o = service.positions(symbol: "EURUSD")
   b = o.find { |x| x.order_type == :OO_OP_BUY }; s = o.find { |x| x.order_type == :OO_OP_SELL }
   service.order_close_by(ticket: b.ticket, opposite_ticket: s.ticket) if b && s
   ```
3. Guard both tickets:
   ```ruby
   begin
     service.order_close_by(ticket: buy_ticket, opposite_ticket: sell_ticket)
   rescue MetaRPC::MT4::ApiError => e
     warn e.code
   end
   ```
