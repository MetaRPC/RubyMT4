# MT4Service — Orders & History (Mid-Level API)

> 5 methods for reading orders: the full open book, just the tickets, the **positions / pending split done for you**, and closed-order history (auto-paged).

**🧩 API Layer:** **MID-LEVEL** — a friendly facade over [`MT4Account`](../MT4Account/2.%20Orders_History/Orders_History.Overview.md). On MT4 an open market order **is** the position.

**Implementation:** `lib/metarpc_mt4/mt4_service.rb`, wrapping `opened_orders` / `opened_orders_tickets` / `orders_history` on `MT4Account` and filtering by `order_type` in Ruby.

**Demos:** `examples/demos/service/04_service_demo.rb`, `sugar/08_sugar_positions.rb`.

## 📋 All 5 methods

| Method | Returns | Low-level equivalent |
|--------|---------|----------------------|
| **`opened_orders(sort:)`** | `[OpenedOrderInfo]` | `opened_orders` (raw passthrough) |
| **`opened_tickets`** | `[Integer]` | `opened_orders_tickets` |
| **`positions(magic:, symbol:)`** | `[OpenedOrderInfo]` | `opened_orders`, filtered to **market** orders |
| **`pending_orders(magic:, symbol:)`** | `[OpenedOrderInfo]` | `opened_orders`, filtered to **pending** orders |
| **`order_history(from_utc:, to_utc:, sort:, page_size:)`** | `[HistoryOrderInfo]` | `orders_history` (auto-paged) |

> **The split.** `positions` keeps only `order_type` `:OO_OP_BUY` / `:OO_OP_SELL` (market = positions); `pending_orders` keeps the `...LIMIT` / `...STOP` types (and drops the `OO_OP_BALANCE` / `OO_OP_CREDIT` ledger rows). Both accept optional `magic:` / `symbol:` filters.

## 📖 Method details

### `opened_orders(sort: :SORT_BY_OPEN_TIME_ASC) -> [OpenedOrderInfo]`

Every open order (market + pending), raw passthrough.

**Usage examples:**

1. List all:
   ```ruby
   service.opened_orders.each { |o| puts "##{o.ticket} #{o.symbol} #{o.order_type} #{o.lots}" }
   ```
2. Newest first:
   ```ruby
   service.opened_orders(sort: :SORT_BY_OPEN_TIME_DESC).first(5).each { |o| puts o.ticket }
   ```
3. Total floating P/L across everything:
   ```ruby
   puts service.opened_orders.sum(&:profit).round(2)
   ```

### `opened_tickets -> [Integer]`

Only the ticket numbers — a cheap poll.

**Usage examples:**

1. Print them:
   ```ruby
   puts "open: #{service.opened_tickets.inspect}"
   ```
2. How many are open:
   ```ruby
   puts service.opened_tickets.size
   ```
3. Diff against a previous snapshot:
   ```ruby
   now = service.opened_tickets
   (now - prev).each { |t| puts "opened ##{t}" }
   ```

### `positions(magic: nil, symbol: nil) -> [OpenedOrderInfo]`

Open **market** orders (= positions), optionally filtered.

1. All positions:
   ```ruby
   pos = service.positions
   puts "open positions: #{pos.size}, floating #{pos.sum(&:profit).round(2)}"
   ```
2. By strategy (magic):
   ```ruby
   service.positions(magic: 600_101).each { |o| puts "##{o.ticket} #{o.profit.round(2)}" }
   ```
3. By symbol:
   ```ruby
   puts "EURUSD positions: #{service.positions(symbol: 'EURUSD').size}"
   ```

### `pending_orders(magic: nil, symbol: nil) -> [OpenedOrderInfo]`

The working pending orders, optionally filtered.

**Usage examples:**

1. All pendings for a symbol:
   ```ruby
   service.pending_orders(symbol: "EURUSD").each { |o| puts "##{o.ticket} #{o.order_type} @ #{o.open_price}" }
   ```
2. By strategy (magic):
   ```ruby
   puts "pending for 130013: #{service.pending_orders(magic: 130_013).size}"
   ```
3. Count all pendings:
   ```ruby
   puts service.pending_orders.size
   ```

### `order_history(from_utc:, to_utc: Time.now.utc, sort: :HISTORY_SORT_BY_CLOSE_TIME_ASC, page_size: 1000) -> [HistoryOrderInfo]`

Closed / deleted orders in a window, auto-paged.

1. Last 7 days, net P/L:
   ```ruby
   h = service.order_history(from_utc: Time.now.utc - 7 * 24 * 3600)
   puts "closed #{h.size}, net #{h.sum(&:profit).round(2)}"
   ```
2. Newest first:
   ```ruby
   service.order_history(from_utc: Time.now.utc - 86_400, sort: :HISTORY_SORT_BY_CLOSE_TIME_DESC)
          .first(5).each { |o| puts "##{o.ticket} #{o.profit.round(2)}" }
   ```
3. Per-symbol:
   ```ruby
   service.order_history(from_utc: Time.now.utc - 30 * 24 * 3600)
          .group_by(&:symbol).each { |s, r| puts "#{s}: #{r.sum(&:profit).round(2)}" }
   ```
